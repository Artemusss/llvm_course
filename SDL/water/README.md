# app_water — моделирование волн на воде (капли)

Программа с динамически меняющейся 2D-картинкой для модуля `SDL` курса
[`lisitsynSA/llvm_course`](https://github.com/lisitsynSA/llvm_course).
Фреймы считаются в модуле логики и выводятся через интерфейс `sim.h`
(`simPutPixel`, `simFlush`, `simRand`).

![Водная рябь](results/water_ripple.gif)

## Что моделируем

Поверхность воды в виде сетки высот. Решается **волновое уравнение** явной
конечно-разностной схемой (классический алгоритм Hugo Elias): высота клетки
на новом шаге считается из соседей на предыдущем шаге, с затуханием. От
каждой капли расходятся концентрические волны, они отражаются, затухают и
интерферируют. Цвет клетки — глубина плюс подсветка по наклону поверхности
(горизонтальный градиент высоты), что даёт «водяной» блик.

- Два буфера высот (`prev`, `cur`) меняются местами каждый кадр.
- Раз в несколько кадров в случайную точку «падает капля» — локальный всплеск.
- Границы поглощают волну (остаются нулевыми).

Сетка 512×256 при окне 1536×768 (`SCALE = 3`: одна клетка — блок 3×3 пикселя).

## Файлы

| Файл | Что это |
|------|---------|
| `app_water.c` | модуль логики — расчёт кадра |
| `app_water.ll` | **обычный** (неоптимизированный) LLVM IR — `clang -emit-llvm -S app_water.c` |
| `app_water-opt.ll` | **оптимизированный** LLVM IR, `-O2` (артефакт доп. задания) — `clang -emit-llvm -S -O2 app_water.c` |

Разница IR: в обычном — вся память как `alloca`/`load`/`store`, операции по
одной; в оптимизированном тот же расчёт **векторизован** (SIMD, `<N x i32>`) и
с развёрнутыми циклами. Внешние `simPutPixel`/`simFlush`/`simRand` в обоих идут
как `declare`, `app` и вспомогательные функции — как `define`.

## Как запустить


```bash
sudo apt update && sudo apt install -y clang llvm libsdl2-dev make git

git clone https://github.com/<ваш-логин>/llvm_course   # свой форк
cd llvm_course/SDL/water

# генерация IR (обычный и оптимизированный)
clang -emit-llvm -S      app_water.c -I.. -o app_water.ll
clang -emit-llvm -S -O2  app_water.c -I.. -o app_water-opt.ll

clang app_water-opt.ll ../start.c ../sim.c -lSDL2 -o app_water -O2
./app_water
```

## Настройка (в начале `app_water.c`)

`DAMP` — затухание (больше → волны живут дольше); `DROP_PERIOD` — кадры между
каплями; `DROP_H` — сила всплеска; `SCALE` — грубость сетки.
